# Pet Water Bottle Shopify Store

A Shopify store selling portable pet water bottles with integrated food containers for dogs and cats.

## Product Overview

**Botella de Agua Portátil para Perros y Gatos** (Portable Water Bottle for Dogs and Cats)

- **Price**: €8.79
- **Rating**: 4.8/5 (293 reviews)
- **Sales**: 2,000+ sold

### Key Features

- 500ml portable water bottle designed for outdoor use
- Integrated food storage compartment
- Combined water bottle and feeding bowl
- Safe, chemical-free plastic material
- Universal design for all dog and cat breeds
- Available colors: Pink, Grey, Green, Yellow

## Store Setup

This repository contains all the files needed to set up and customize your Shopify store.

### Project Structure

```
/
├── README.md                    # This file
├── products/                    # Product data and descriptions
├── theme/                       # Shopify theme customizations
├── images/                      # Product images and assets
├── scripts/                     # Automation scripts
├── shopify.app.toml            # Shopify app configuration
└── docs/                        # Additional documentation
```

## Getting Started

1. Connect this repository to your Shopify store
2. Customize theme files in `/theme`
3. Add product images to `/images`
4. Update product details in `/products`
5. Deploy changes to your live store
